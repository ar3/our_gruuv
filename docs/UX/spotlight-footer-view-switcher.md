# Spotlight footer View switcher

**Superseded by the full footer pattern.** See **`docs/UX/spotlight-footer.md`**.

View remains a link-style dropdown in the **right** column of the spotlight footer (stacked with Sort, Direction, and Spotlight). Do not implement View-only upgrades in isolation when touching an index—bring the footer in line with `docs/UX/spotlight-footer.md` (pills left; View / Sort / Direction / Spotlight right).
